MoonTerm — a VT emulator core written in MoonBit

The engine below is the compiled MoonBit library, not a reimplementation. Every screen you see here came out of the same code moon test checks against xterm.js.

Feed a byte stream

Write ESC and BEL as words; they are substituted with the real control bytes. Everything else is sent through verbatim, so escape sequences can be typed here exactly as a program would emit them.
